# jellyboost
🔊 **JellyBoost**: Audio volume booster &amp; compressor for Jellyfin Web.  ✨ **Features:** - Boost audio up to 400% with built-in dynamic limiter - Prevents clipping and distortion at high volume levels - Sleek purple hover-reveal slider control panel - Zero-UI footprint when idle  Pure vanilla JS with built-in Web Audio API nodes.
