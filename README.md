# jellyboost

[![Install JellyBoost](https://img.shields.io/badge/INSTALL-JELLYBOOST-purple?style=for-the-badge&logo=tampermonkey)](https://raw.githubusercontent.com/stantonmike2004-pixel/jellyboost/refs/heads/main/boost.js)

🔊 **JellyBoost**: Audio volume booster & compressor for Jellyfin Web.

✨ **Features:**
- Boost audio up to 400% with built-in dynamic limiter
- Prevents clipping and distortion at high volume levels
- Sleek purple hover-reveal slider control panel
- Zero-UI footprint when idle

Pure vanilla JS with built-in Web Audio API nodes.
